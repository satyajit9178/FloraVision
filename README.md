# Flora Vision

Flora Vision is a responsive plant-themed frontend website built using React, Vite, and Tailwind CSS.  
The project focuses on clean UI design, reusable components, and responsive layouts.

---

## Live Demo

https://flora-vision-eight.vercel.app/

---

## Features

- Responsive design
- Reusable React components
- Modern UI layout
- Built with Vite for fast performance
- Styled using Tailwind CSS

---

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

## Installation and Setup

Clone the repository:


git clone https://github.com/YOUR_USERNAME/flora-vision.git


Move into the project folder:

cd flora-vision
```

Install dependencies:

npm install


Start the development server:

npm run dev


## Production Build

npm run build
